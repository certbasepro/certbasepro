# Contributing to CertBase

CertBase is free because the community keeps it accurate. If you've passed a certification exam, you can make the next person's prep better.

**Ways to help**
- **Submit a question** for an exam you've passed.
- **Review existing questions** — flag anything wrong, outdated, or unclear.
- **Improve explanations** — make the "why" clearer.
- **Moderate discussions** — keep threads useful and accurate.

**What we value:** accuracy over volume, plain-English explanations, and honesty about exam changes (codes and objectives rotate — flag stale content).

Contributors are acknowledged for what they add. Start here → https://certbase.pro/contribute
